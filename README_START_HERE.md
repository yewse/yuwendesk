# 语文备课工作台｜工程交付包 V1.0

**这是工程规范、合同、例子和验收任务，不是已开发软件，也不含可以给教师安装的EXE。**项目代号YuwenDesk。日期2026-09-19。

目标：使用Grok 4.6编码智能体自动完成开发、测试和打包。教师最终只安装、点击桌面图标和少量确认，不启动服务、不输入网址、不装开发环境。

## 给项目持有人的使用步骤

1. 将本ZIP解压或提供给有文件读写、终端、Git和Windows测试能力的编码智能体环境。普通聊天窗口不自动具有这些能力。
2. 先提供AGENTS.md、docs/ENGINEERING_SPEC.md、planning/AUTONOMOUS_WORKPLAN.md；用GROK_START_PROMPT.md启动。
3. 通过持有人界面提供必要授权与费用上限。开发密钥放受控秘密环境，不贴进提示词或仓库。缺少签名、Windows或真实账户时，智能体只能如实报告阻断。
4. 先验收G01安装骨架，再扩展功能。不要以网页演示或源码目录替代安装包。
5. 每个阶段核对真实证据与剩余缺口。最终接收签名安装包或明确的测试构建，不接受虚构“全部通过”。

## 阅读顺序

- AGENTS.md：智能体不可违反的执行规则。
- docs/ENGINEERING_SPEC.md：完整产品及技术规范；有Word阅读版。
- docs/MODULES_AND_SKILLS.md：12个业务模块及语文方法。
- docs/IPC_AND_STORAGE.md：接口、数据保护、事务与存储边界。
- contracts/：数据Schema、IPC、状态机、SQL基线。
- acceptance/：60项原始业务要求与桌面/安全等扩展案例，均待执行。
- planning/：48个工作包、外部条件、交接模板、发布清单。
- examples/：明确自拟的有效与故意无效输入，不是官方教材或真题。
- baseline/：原始60条需求及未修改的XLSX，不得删除。
- reports/：仅本次文档包结构检查，不是应用测试。

## “零人工”的真实边界

不要求用户或教师写代码。但账户授权、费用、教材使用权、签名身份和实际教学决定仍属于持有人/教师。模型不能自行批准。软件的代码完整、资料覆盖和教学效果三个状态分别报告。

首版按Windows11 x64设计，其他平台未承诺。应用本地运行不代表AI离线生成；新的Grok生成需要可用互联网、账户和明确的数据外发授权。断网仍可查阅、编辑、展示和导出现有内容。
