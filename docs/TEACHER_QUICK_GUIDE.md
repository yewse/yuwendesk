# 语文备课工作台｜教师快速指南

本指南对应当前界面中的“备下一课”“我的课程”“资料”“帮助与设置”。当前提供的是工程验证版，不是已经完成正式签名与教学专业复核的教师发行版。

## 安装与打开

只使用学校或项目负责人确认的安装来源。安装或离线更新时，应看到可信发布者验证；如果系统提示发布者未知、文件被改动或来源不明，请停止并联系支持人员，不要绕过系统保护。当前测试构建尚不是正式签名的教师发行版。

## 第一次设置

打开“帮助与设置”可以查看模型连接与费用边界、备份、离线更新和最小诊断。班级、年级、教材版本、单元、课文和实际课时在“备下一课”的第一步填写，并随备课会话保存。教师不需要编写提示词；没有已授权的真实服务、网络或可用预算时，可使用本地自拟模式，不会假装调用了模型。模型生成内容必须由教师复核，工程测试替身也不代表真实备课质量。

## 备下一课

“备下一课”按一个可恢复流程工作：先保存班级、教材和课时，再选择已导入资料的精确片段，或在页面中粘贴并导入资料；随后选择本地自拟或模型辅助，填写教学重点、核心任务和答案范围，生成方案并查看内容来源。软件审查通过后仍需教师确认，才能导出五文件。模型不可用时只会显示错误并提供显式的本地自拟入口，不会在后台反复扣费。

资料片段会显示标题、版本、范围和摘要；模型模式还需要对本次片段单独授权。来源变化、审查过期或重启中断时，流程会回到可安全恢复的步骤，不会把半成品当成已确认方案。

## 三类五文件

导出结果固定为三类五文件：课堂 PPT、学生讲义 DOCX/PDF、教师讲解版 DOCX/PDF。页面会显示 plan、revision、bundle 与每个文件的校验摘要；五个文件只有在同一次原子发布全部成功后才显示为已导出。每次生成或修改后都要使用同一修订版本；旧纸本不会自动更新。

## 课堂展示

五文件导出完成后，可以从“备下一课”打开应用内课堂展示。展示窗口只读取当前已审查的方案，先呈现任务；提示和答案必须分别点击后才揭示，关闭展示不会修改方案，也不依赖 Office/WPS 或本地网络服务。

Office/WPS 兼容性仍是另一项验收：若在外部打开或编辑导出的 Word 或 PPT，目标电脑需安装可用版本，并由教师检查分页、字体、投影比例和内容完整性。外部编辑不会自动回写工作台中的方案；尚未实际完成的 WPS 保真检查不能由应用内展示替代。

## 只改一处

需要调整时，在“我的课程”打开已有方案，找到“一处修改”，再从“本次只改”选择实际课时、独立学习、联结、题目/答案范围或版式。先点“预览改动”，核对后再点“确认并同步更新”；若存在版本冲突，应先比较差异，不覆盖较新的修改。

## 课后观察

课后反馈是可选的。只有确实实施了方案并观察到结果时才记录；无法判断时选择“证据不足”。本机课堂观察可以删除，但已经导出的副本、离线副本或他人持有的副本不能由应用召回。

## 模型辅助归因

模型辅助归因从一开始就是流程的一部分，但必须先完成五项本地测量检查：题目、评分、可比条件、样本覆盖和实际实施。任一关键条件不足就不调用模型。归因结果只是待验证假设，不是教学效果结论，也不能据此承诺成绩变化；接受提案只生成可复核的修改预览，不会直接改课时或成品。

## 隐私与外发

资料默认先在本机处理。学生材料在没有真实隐私授权和逐次外发许可时只能本地使用，不得发给模型。每次外发都必须由已授权流程批准最小必要的结构化字段；原始作品、姓名、身份信息、本机路径、完整提示词和本机观察摘要不应进入模型请求。学生敏感资料升级为认证加密后不能降级为普通资料。

## 备份与换电脑

在“帮助与设置”中可创建本机备份，或用至少 14 个字符的强口令导出跨机加密备份。备份口令无法找回；遗忘后不能恢复该加密备份。恢复会先检查备份，不应直接覆盖现有数据。API 凭据不会随备份迁移，换电脑后需要重新连接已授权服务。

## 离线更新

“可信离线更新”只接受与当前安装版本内置信任身份一致的更新包。先“选择并验证离线更新包”，验证成功后再“仅暂存已验证更新”。没有可信发布身份时更新会被阻止，当前界面不提供绕过按钮；暂存不会自动关闭或重启应用。

## 诊断

“最小诊断”会先显示完整预览，再由教师决定是否保存。诊断包默认不包含资料正文、学生作答、文件名、本机路径、API 密钥、提示词或模型完整输入输出，也不会自动上传。发送前仍应逐项查看预览。

## 卸载与数据

卸载默认保留本机资料，避免误删课程与备份。真正删除资料需要单独确认，并查看当前数据库、应用受管备份和外部副本三个范围；外部副本无法自动撤回。需要交接设备时，先完成受控备份和恢复验证，再按学校数据流程处理本机数据。

## 已知限制

当前工程候选仍未签名，也缺少可信时间戳、干净标准用户 Windows 安装验收、Office/WPS 兼容复核、真实 API 执行证据、合法现用教材覆盖、真人教师教学专业复核及授权分发位置。用户已给出的隐私外发许可只适用于约定范围，不能代替逐次最小必要字段确认。现有工程测试、SBOM、校验清单、合成材料或模型自审不能替代这些条件。正式状态以随发行包提供的《最终发行状态》和《已知限制与未关闭发行门》为准。
