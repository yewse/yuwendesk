# G12-T07 AI 主导教师备课流程设计

## 目标

教师无需理解备课系统的内部状态机。主界面只表达一个价值：导入教材或教师资料，填写少量本课信息，由 AI 完成教学方案规划与教学文件生成。

## 教师可见流程

1. **导入资料**：在“备下一课”内直接拖放或选择 txt、md、csv、pdf、docx、xlsx、pptx，也可选择已经导入的资料。资料卡只显示标题、版本、类型与短摘要。
2. **填写本课信息**：主表单只要求年级、课题和课时。班级默认为“当前班级”，教材名从所选资料标题派生；班级、教材版本、单元和补充要求放在“更多设置”内。
3. **AI 完成备课**：一次点击依次保存本课信息、绑定经核验资料、调用模型生成方案并运行软件完整性检查。教师看到方案摘要、课堂任务和需要核实的事项，不看到状态枚举、UUID、revision 或 bundle。
4. **一次人工确认**：教师确认当前方案后，应用在同一次操作中登记确认并生成教学文件。确认不能由软件冒充。
5. **直接使用**：结果按“课堂课件、学生讲义、教师教案”分组显示；主界面不显示哈希和字节数。校验信息只在折叠的“技术详情”内提供。

## 信息架构

- 页面标题为“把资料交给 AI，备好这一课”，副标题直接说明输入和输出。
- 进度只保留“导入资料 / 填写本课信息 / AI 生成结果”三段。
- “继续上次备课”使用人类可读状态，例如“AI 方案待确认”“教学文件已生成”，不显示 `READY_TO_EXPORT` 等枚举。
- “备课草稿”和“系统状态”不再出现在备课主页面；系统健康信息仍由顶部状态与帮助设置承担。
- 模型或导出失败时显示教师可执行的下一步；错误码与内部标识不进入主文案。

## 数据与安全边界

- 沿用现有 `PreparationService`、严格模型合同、来源 SHA-256、软件审查、原子五文件发布和失败回滚，不降低任何门禁。
- AI 模式仍要求教师逐次勾选必要片段外发授权；未授权不能开始生成。
- 一次“AI 完成备课”不自动重试真实模型，不绕过预算，不自动确认教师方案。
- 本地自拟仅在 AI 失败时作为显式备用入口，不与主流程并列争夺注意力。
- 文件同名且需要版本关系确认时不自动猜测，提示教师到资料管理中确认；重复原件可复用已有版本。

## 组件边界

- `aiFlow.ts`：无 React 状态，按修订号串行编排 context → session → sources → build → review，以及 confirm → export；任何一步失败立即返回，不执行后续步骤。
- `AiPreparationStart.tsx`：文件导入、已有资料选择、必要信息、更多设置、外发授权和单一主按钮。
- `AiPreparationResult.tsx`：方案预览、一次确认、文件分组、课堂展示与折叠技术详情。
- `PreparePage.tsx`：加载/恢复数据、文件导入适配、调用编排器和显示教师可理解的阶段信息。
- `App.tsx`：真实入口只渲染备课工作流和必要的平台警告，不追加草稿/系统状态卡。

## 验收标准

- 完整 `App` 的初始服务端渲染能直接说明“资料 + 少量信息 → AI 结果”，且不渲染备课草稿或系统状态卡。
- 恢复任一 session 状态时，界面没有裸状态枚举或计划/修订/成品包 UUID。
- 严格假网关证明一次 AI 操作按正确修订顺序完成生成和审查，且不调用 confirm/export。
- 严格假网关证明一次人工确认按正确修订顺序完成 confirm/export。
- 未选资料、未填课题或未授权时主按钮不可用；无需填写教学重点、核心任务和答案范围。
- 实际生产构建通过隔离 Electron/SQLite 渲染走查，覆盖初始页、方案页和完成页。
- 全量单测、typecheck、lint、build、合同校验和 `git diff --check` 通过；真实 API、WPS、签名、分发和真人教师专业复核状态不因 UI 重做而提升。

## 教师业务实跑与专业质量判断

- 使用 `C:\Users\ye\Desktop\初中语文教材` 中的真实 PDF，经新候选的真实文件导入、SQLite、来源核验、模型生成、软件检查、确认、教学文件生成与课堂展示走完一次业务；不以静态夹具代替。
- 选择一篇可从教材中核验的课文。教材原文是事实依据；LLM 对课程标准和考试要求的补充必须标为“AI 补充参考”，无法核验的具体条款进入 unknowns，不得冒充正式课程标准或考试文件。
- 真实 API 只使用应用已经通过 safeStorage 保存的凭据。检查配置时只读取 provider/model/预算/联网状态，不读取、输出或复制 API key；没有受保护凭据则记录 `BLOCKED_EXTERNAL`。
- 教师视角走查记录完成任务所需输入、点击次数、等待反馈、错误恢复、主文案可理解性和产物可找到性。
- AI 模拟专业评审采用 10 项、每项 0–4 分量规：课程目标对齐、单元定位、文本细读证据、目标可测量性、核心任务统摄、活动认知进阶、学生主体与差异支持、评价一致性、时间可行性、答案开放性与误解预判。达到 34/40、无单项低于 3、无来源幻觉/隐私泄露时仅可标 `READY_FOR_HUMAN_EXPERT_REVIEW`；否则标 `NEEDS_REVISION`。没有真实特级教师复核时永不标 `CERTIFIED` 或“达到特级教师标准”。
