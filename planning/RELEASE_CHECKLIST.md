# 发布验收清单

默认状态：NOT_RUN。软件、资源、课堂三个完成状态独立。

## 软件发布门
实际离线安装包存在；appId稳定；标准账户桌面启动；无控制台/网址/监听服务；主流程有真实功能；本地离线可用；导出可编辑且一致；密钥和学生原文无泄漏；备份恢复与迁移经过实测；已知P0/P1为0；全部必需门没有FAIL/BLOCKED/NOT_RUN。

## 外部条件门
真实API权限、费用和数据外发范围由持有人批准；生产签名可验证；发布位置获授权。无签名只能TEST_BUILD；签名不保证SmartScreen无告警。权限不足不许建议关闭系统保护。

## 证据门
每条要求都有实现位置/测试/结果/限制；Windows截图确由Windows测试取得；真实API与mock分开；源码commit、安装包hash、SBOM、依赖锁、更新身份、来源覆盖和用户手册齐全。

## 教学边界
不捏造课标映射、官方真题、学生记录或研究结论；尚无教师校准就标教学适配未验证；不能在营销或完成报告承诺持续提分。所有模板和自拟样例标明性质。

## 持有人接收结果
RELEASE_READY / CONTROLLED_TRIAL / UNSIGNED_TEST_BUILD / BLOCKED四种总状态之一，并列出软件门、外部条件和教学状态的原始记录。不能仅给总体成功率掩盖关键失败。
