# 编码智能体自主实施计划

本文件不是工期保证。48个工作包和12道阶段门是可执行范围划分，不代表已经完成。精确依赖见work-packages.json。任何外部条件缺失都应分开标记，不等待无关授权而停掉全部安全本地工作。

## 仓库必须最终提供的脚本

这些脚本是待开发仓库应实现的接口，不是本工程文档包已经包含的应用命令：

- verify:contracts：结构、引用、状态和迁移合同。
- lint / typecheck / test:unit / test:integration：代码规范与可重复行为。
- test:e2e：真实Electron窗口，不只模拟DOM。
- build:win：锁定依赖的Windows x64构建，输出离线安装包。
- test:installer：干净VM安装、桌面图标、退出、卸载保留资料；没有VM时BLOCKED。
- test:api:live：显式授权、限额、grok-4.6真实探测；绝不默认在每次单测产生费用。
- test:security / test:backup / test:upgrade / test:performance：各项实际证据。
- release:verify：归集证据和原需求覆盖；未满足门槛以非零状态退出。

开发/CI可以执行命令；教师使用指南不得出现这些命令。无Linux模拟可替代Windows安装验收。真实签名由受控凭据系统执行，智能体不读取私钥。

## 每个工作包的执行循环

读取相关需求和验收 → 检查环境与依赖 → 先补失败测试或fixture → 实现最小功能 → 运行测试 → 定位失败 → 有界修复 → 输出证据 → 小步提交 → 更新PROGRESS与HANDOFF。没有实际运行的项保留NOT_RUN。单一问题3轮无实质进展时保留证据、给出替代路径，并继续不相关的安全任务。

验收规则冲突先形成ADR，不得悄悄选择容易的规则。已知P0/P1没有关闭时，不发布正式教学版。自动化校验通过不等于专业教研或提分已验证。

## 阶段概览

### G00 环境与授权

1. 核实Grok4.6能力和账户；交付：ENV_LOCK.json。
2. 锁定开发依赖与许可证；交付：EXTERNAL_INPUTS.json。
3. 登记Windows运行环境与资源权限；交付：SBOM初稿。
4. 建立受限命令、费用与外部阻断清单；交付：真实探测或阻断记录。

### G01 先交付安装骨架

1. 原生窗口与中文导航；交付：可安装工程EXE。
2. 单实例、保存与退出生命周期；交付：窗口截图。
3. 当前用户离线NSIS安装与快捷方式；交付：进程与监听记录。
4. 干净Windows标准账户安装证据；交付：安装报告。

### G02 本地安全数据基础

1. 受限IPC及Schema门；交付：IPC实现。
2. SQLite迁移与单写入者；交付：迁移文件。
3. DPAPI凭据与敏感payload加密；交付：权限与加密测试。
4. 版本并发及事务事件；交付：无明文凭据报告。

### G03 资料与来源

1. 安全解析导入和资源限制；交付：导入器。
2. 来源版本与精确锚点；交付：本地检索。
3. 中文FTS与短词回退；交付：来源viewer。
4. 资源缺失、重复、撤销和覆盖界面；交付：来源冲突案例。

### G04 模型与可靠任务

1. Grok provider及真实能力探测；交付：provider实现。
2. 有限工具和结构化合同；交付：任务状态。
3. 预算、取消、超时和持久检查点；交付：usage报告。
4. mock协议矩阵与真实联网烟测；交付：真实API或BLOCKED证据。

### G05 教学业务M01至M08

1. 任务与课标教材双对齐；交付：三类完整课型fixture。
2. 内容及未知学情处理；交付：LessonPlan输出。
3. 联结三条时间线与方法库；交付：模块trace。
4. 核心任务、评分范围与课时编排；交付：语义反例报告。

### G06 同源材料交付

1. 结构化编辑和撤销；交付：真实导出文件。
2. DOCX与PPTX可编辑导出；交付：渲染图。
3. PDF与本地课堂展示；交付：manifest。
4. 逐格式渲染和同源一致检查；交付：编辑器兼容记录。

### G07 审查与一处修改

1. 确定性与模型审查分层；交付：ReviewReport。
2. 受影响依赖失效和重算；交付：ChangeProposal。
3. 单方案与最少选择界面；交付：变更diff。
4. 争议解释和失败降级；交付：一致性回归结果。

### G08 反馈与教学纠正

1. 采用与实际授课分离；交付：Observation。
2. 可选观察和样本范围；交付：改进卡。
3. 先查题目评分再提出原因假设；交付：事件记录。
4. 偏好与效果双轨更新及撤回；交付：证据边界测试。

### G09 保护与恢复

1. 一致备份和跨机加密恢复；交付：备份恢复结果。
2. 敏感重分类及彻底删除路径；交付：安全测试。
3. 诊断最小化与故障注入；交付：诊断样包。
4. 注入/越权/文件资源攻击测试；交付：威胁检查清单。

### G10 升级与性能

1. 签名更新清单和离线更新；交付：升级证据。
2. 迁移失败恢复与不兼容回退；交付：恢复证据。
3. 中文路径/缩放/辅助使用；交付：性能原始记录。
4. 冷启动检索导出性能与压力；交付：兼容矩阵。

### G11 完整发行验收

1. 执行全案例并追踪所有原需求；交付：发行安装包或测试构建。
2. 核对资源覆盖和已知缺口；交付：release-evidence.json。
3. 签名EXE和SBOM及哈希清单；交付：校验清单。
4. 最终交付及真实状态报告；交付：中文用户手册。
